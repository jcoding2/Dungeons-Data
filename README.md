# Dungeons & Data

Dungeons and Data is a D&D 5th edition-compatible client (kinda like D&D Beyond) for Linux only right now (Windows and macOS support is planned for the future) and it *only* has the System Reference Document 5.2.1 content. You can add the other stuff. (For the love of Wizards of the Coast, do **not** share that stuff online.)

## Spellsets
I'm doing these in *alphabetical order*. That means that Warlock and Wizard are last, and Bard and Cleric are first. The current spellset I'm doing is the Druid cantrips.
